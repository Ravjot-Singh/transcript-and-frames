Transcript & Frames — test console

Send real requests to both endpoints and inspect exactly what went out and came back.

This page is a testing tool, not a production frontend. The API key you type below is kept in this browser's local storage and sent as the x-api-key header. A browser cannot hold a secret, so never put a production key into a page you expose publicly — set ENABLE_DEMO=false on a deployment that strangers can reach.

Served from the same origin as the API, so no CORS configuration is involved. Frame thumbnails below load straight from Cloudinary's CDN — none of those bytes pass through the service.

POST /v1/translate

Derives an audio-only Cloudinary URL, streams that audio to Whisper, returns English text. Source language is detected, never configured.

POST /v1/frames

  
Chooses how many frames the duration deserves, places
  them by inverse-normal quantiles, and returns one Cloudinary URL each. No media is fetched,
  decoded or stored by the service.
